roomcorr － 房間修正（測量 → 分析 → 目標曲線 → 濾波器 → 低頻控制 → 匯出）
=====================================================================

【運作方式】
  測量：麥克風 + DAC 直接播放掃頻（roomcorr 自己播放，不經過 BlackHole）
  聆聽：Roon / Music → BlackHole 2ch → roomcorr（FIR 卷積）→ DAC

【安裝（只做一次）】
1. 把整個資料夾解壓縮到桌面。
2. 在「終端機」執行：   bash ~/Desktop/RoomCorr/Install_RoomCorr.command
   需要 Python 3.10+（沒有的話先 brew install python@3.12）。
   腳本會：建立環境 → 編譯 App → 放進 /Applications → 詢問是否安裝 BlackHole → 自動檢查能不能啟動。
3. 第一次開啟，允許「麥克風」存取。
   若啟動失敗，錯誤會顯示在視窗，並寫入 ~/Library/Logs/RoomCorr.log。

【介面（左側導覽）】
 量測
   - 圖上選麥克風位置（左 30 cm／中央／右 30 cm），右邊「量測矩陣」選要量哪一格
     （左喇叭、右喇叭、雙聲道 × 三個位置）。點格子→按「開始量測」可重測單一格；
     「依序量測全部」會一路量完並提示何時移動麥克風。
   - 「測試音量」：量測前確認麥克風輸入約 −30 ～ −10 dBFS。
   - 「測量設定…」：輸出裝置與聲道、取樣率、掃頻長度、音量、重複次數、低音砲數量與位置。
 分析
   - 圖上：橘＝量測、虛線＝目標、藍＝校正後。點「量測矩陣」的格子可看每一組。
   - 右上：標準／夜間／電影 三個設定檔，以及「校正 開／關」一鍵開關（選單列圖示也能切）。
   - 下方可直接選目標預設、相位類型、MIMO 聯合校正，「預覽」或「套用並匯出」。
 目標曲線
   - 預設（平坦／低頻增強／高頻柔和）或「自訂」：低頻增強、低頻轉折、高頻傾斜、校正上限頻率。
   - 也可以直接在圖上拖曳藍點；雙擊新增點、右鍵刪除。三個設定檔各有自己的目標。
 濾波器
   - 相位類型（最小相位／線性相位／混合）、長度 16384／32768／65536、取樣率 44.1／48／96 kHz、
     平滑 1/3／1/6／1/12 oct、最大提升 0–12 dB、最大衰減 0–24 dB、MIMO 聯合校正（300 Hz 以下，左右聲道與多位置一起求解）。
   - 「進階設定 / FIR 工具…」：避免填深谷（DRC 式）、預振鈴上限、相位修正上限（可到 20 kHz）、左右時間對齊；
     以及 rePhase 式 FIR 工具（線性相位分頻、PEQ、全通、延遲）。
 低頻控制
   - Bass Control：低頻目標增益、轉折頻率、最大提升、衰減控制（加強削減低頻峰以縮短餘音）、限制最大提升。
   - MSO 多低音砲：每顆低音砲的增益、延遲、反相，可手動調，也可按「自動最佳化」（遺傳式搜尋，含兩個全通濾波器）。
     「分頻與輸出聲道…」設定分頻、方法（MSO／FIR 最小平方）、DAC 輸出聲道；「套用到設定檔」會自動對齊主喇叭與低音砲。
 匯出
   - 左右聲道各存一個 WAV（例如 std_L.wav、std_R.wav；有低音砲時也含每顆低音砲）。
   - 預設資料夾 ~/Desktop/AutoEq_Project/filters；「儲存前先詢問」會列出檔案並提醒同名檔案將被覆蓋。
   - 匯出的同時，這組濾波器也會存成目前的設定檔（標準／夜間／電影），之後可一鍵切換。

【第一次聆聽設定】
1. 「音訊 MIDI 設定」：BlackHole 2ch 的取樣率與 roomcorr 的取樣率相同（例如 48000 Hz）。
2. Roon：輸出裝置選 BlackHole 2ch，關閉 Roon 內建的卷積／DSP，音量固定。
3. 點左下角「輸出裝置」卡片：輸入選 BlackHole 2ch、輸出選你的 DAC，按「開始音訊」。
4. 在「分析」頁按右上「校正 開」。

【注意】
  - 濾波器含延遲：混合相位約 30 ms；線性相位 = 長度 ÷ 2 ÷ 取樣率（32768 taps、48 kHz 約 341 ms）。看影片可能不同步。
  - 濾波器若有提升，大音量時可能削波：到「輸出裝置」卡片調「輸出微調」。
  - 多顆低音砲需要多聲道 DAC／音訊介面（Omnia 只有 2 個輸出聲道）。含低音砲的設定檔在 Bypass 時低音砲不出聲。
  - 輸出不能選 BlackHole 或與輸入相同的裝置（會回授）。
  - 3 個量測位置是最少的數量；位置越多，修正越穩定。

【⚡ 自動最佳化並套用】（在「分析」與「濾波器」頁）
量測完成後按一下即可：程式依量測資料自動決定修正範圍（喇叭延伸到多低、高頻資料是否可靠）、
最大提升／衰減、平滑、相位類型、目標曲線（平坦，高頻微降）、是否時間對齊，
試算多組候選後選誤差最小的一組，存入目前設定檔（標準／夜間／電影）並開啟校正。
之後仍可在各頁微調。
